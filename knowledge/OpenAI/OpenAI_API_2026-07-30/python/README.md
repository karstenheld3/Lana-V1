## Documentation Bugs Found

### IN06/IN09: Token Counting Response Attribute
- Docs may reference `total_tokens` but SDK response uses `input_tokens` attribute
- `InputTokenCountResponse.input_tokens` is the correct field

### IN13: Function Tool Format (Responses API)
- Responses API uses FLAT tool format: `{"type": "function", "name": "...", "parameters": {...}}`
- NOT the nested Chat Completions format: `{"type": "function", "function": {"name": "..."}}`
- This is a common confusion point for developers migrating from Chat Completions

### IN15: Accessing Response Text
- Response output items are `ResponseOutputMessage` objects with `content` (list)
- Use `response.output_text` for direct text access (convenience property)
- NOT `item.text` on individual output items

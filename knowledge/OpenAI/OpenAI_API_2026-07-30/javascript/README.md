## Key Differences from Python SDK

- JS SDK v7.x uses camelCase: `client.fineTuning` vs Python `client.fine_tuning`
- JS SDK v7.x uses camelCase: `client.vectorStores` vs Python `client.vector_stores`
- Chat Completions tool format nests under `function`: `{ type: "function", function: { name: "..." } }`
- Responses API tool format is flat: `{ type: "function", name: "...", parameters: {...} }`
- Streaming uses `for await (const event of stream)` pattern
- Audio speech returns Response object, use `.arrayBuffer()` for bytes
